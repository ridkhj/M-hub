## O que foi feito
- O frontend antigo (em Vanilla JS) foi totalmente reescrito em React com Vite.
- Utilização de componentes, props e estados (useState, useEffect, useMemo).
- Implementação de roteamento com React Router (Rotas de Login, Cadastro e Dashboard).
- Consumo da API via `fetch` isolado (`services/api.js`), com tratamento de `loading` e `erro`.
- Interface inteiramente nova baseada em UX (tema escuro estilo Spotify).
- Melhorias aplicadas a partir da Avaliação Heurística (E6): Modais, Toasts, Skeletons e Dialogs de Confirmação.
